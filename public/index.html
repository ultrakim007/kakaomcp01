        💡 카카오맵 API & PlayMCP 연결 방법

        지금 API 키가 없어도 체험 모드로 모든 화면을 써볼 수 있어요! 실제 전국 지도를 붙이려면 아래 3단계만 따라 하세요.

        1. 카카오 디벨로퍼스(developers.kakao.com)에서 내 앱을 만들고, [제품 설정] → [카카오맵] → [사용 설정]을 켜주세요.
        2. [앱 키] 메뉴에서 REST API 키를 복사한 뒤, 프로젝트 폴더의 .env 파일에 KAKAO_REST_API_KEY=복사한키로 저장하세요.
        3. 서버를 다시 시작하면 자동으로 실시간 카카오맵 모드로 바뀝니다!

        🤖 PlayMCP 카카오맵 AI 채팅에서도 이렇게 물어보세요!
