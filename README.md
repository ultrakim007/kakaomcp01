# 오늘의 30분 건강 산책·자전거 코스 메이커

시니어분들도 쉽고 크게 볼 수 있도록 만든 **반응형 건강 길찾기 웹앱**입니다.
**카카오 디벨로퍼스 카카오맵 REST API**(키워드 장소 검색, 도보 경로, 자전거 경로, 정적 지도)와 **PlayMCP 카카오맵 도구** 활용 흐름을 기반으로 제작되었습니다.

## 주요 기능

- **체험 모드 내장**: 카카오 API 키를 넣기 전에도 인기 산책·자전거 코스로 모든 기능을 바로 체험할 수 있습니다.
- **실시간 카카오맵 연동**: `.env`에 `KAKAO_REST_API_KEY`만 넣으면 대한민국 전역 장소 검색 및 실제 도보(`ACCESSIBLE` 편안한 길 / `BROAD_FIRST` 넓은 길 / `SHORTEST` 최단 경로)·자전거(`BIKE_ONLY` / `ACCESSIBLE` / `SHORTEST`) 경로와 정적 지도가 즉시 연동됩니다.
- **시니어 친화 UI**:
  - 상단 **글씨 더 크게** 토글 버튼
  - **🔊 소리로 듣기** (음성 안내 읽기)
  - **📋 카톡 공유용 복사** 버튼 & **카카오맵 바로가기** 버튼
  - **도보 vs 자전거 한눈에 비교** 탭

## 실행 방법

1. 프로젝트 폴더에서 실행:
   ```bash
   npm start
   ```
2. 브라우저에서 `http://localhost:3000` 열기

## 실시간 카카오맵 API 연결 방법

1. [카카오 디벨로퍼스](https://developers.kakao.com/) 로그인 → `[내 애플리케이션]` → 앱 선택(또는 새 앱 생성)
2. `[제품 설정]` → `[카카오맵]` → **사용 설정 ON**
3. `[앱 키]`에서 **REST API 키** 복사
4. `.env.example`을 `.env`로 복사한 뒤 키 입력:
   ```env
   KAKAO_REST_API_KEY=여기에_REST_API_키_붙여넣기
   PORT=3000
   ```
5. 서버 재시작 (`npm start`)
